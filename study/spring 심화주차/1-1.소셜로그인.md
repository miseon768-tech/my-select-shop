# 챕터1-1 : 소셜 로그인

카카오 OAuth2 사용을 위한 카카오 디벨로퍼스 애플리케이션 등록 및 설정 흐름 정리.

---

## 소셜 로그인 배경

- 사용자 : 웹사이트마다 반복되는 회원가입 및 계정 관리 부담
- 운영자 : 개인정보 보호 및 보안 유지 부담
- **해결책** : OAuth 기반 소셜 로그인 도입

## OAuth란

- 비밀번호 제공 없이 외부 서비스에 접근 권한을 위임하는 개방형 표준 프로토콜
- 대표 제공자 : 구글, 페이스북, 네이버, 카카오

---

## 카카오 디벨로퍼스 설정 순서

1. **애플리케이션 등록** : [developers.kakao.com](https://developers.kakao.com/console/app) 에서 앱 아이콘, 앱 이름, 사업자명 입력 후 저장
2. **사이트 도메인 등록** : 플랫폼 > Web 플랫폼 등록 > `http://localhost:8080` 입력
3. **Redirect URI 등록** : 카카오 로그인 > Redirect URI 항목에 `http://localhost:8080/api/user/kakao/callback` 입력 후 활성화 ON
4. **동의 항목 설정**
    - 닉네임 → 필수 동의
    - 카카오계정(이메일) → 선택 동의
